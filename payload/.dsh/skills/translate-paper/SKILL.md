# 文献翻译与入库

本技能把一个学术论文翻译成**规范中文 Markdown**，并登记进文献库。

所有路径都相对于本技能所在目录解析：
- 技能目录：`<workspace>/.dsh/skills/translate-paper/`
- 工作区根目录：技能目录上溯三级（即 `文献翻译插件/`）
- 工具目录：`<workspace>/tools/`
- 文献库：`<workspace>/library/`
  - `library/papers/` 原始 PDF
  - `library/extracted/<slug>/` 抽取的中间文本（`<slug>.md`、`.json`、`.report.txt`）
  - `library/translations/<slug>/<slug>.md` 最终中文译稿
  - `library/library.json` 分类与元数据索引
  - `library/README.md` 分类总览（自动生成，可在右侧文档预览中阅读，支持公式渲染）

## 硬性要求（用户明确指定的九条，不得违背）

1. **专有名词、术语、人名、地名、引用标记一律准确翻译**；确无通用译法的，在前后加 `*` 号并保留原文，例如 `*Seebeck*`、`*zT*`。
2. **保持中心思想不变**；不得增删论点、不得改写结论强度（"may" 不能译成"必须"）。
3. **不要保留双栏排版**，输出为正常的中文论文格式（单栏、段落连续）。
4. **图片只翻译图注（caption），跳过图片内容**。图注格式：`**图 1.** 说明文字`。
5. **参考文献列表不翻译**，但**正文中的引用标注必须保留**（`[1,2]`、`[3–5]`、`(Smith et al., 2020)` 等原样保留在句中）。
6. **被分页/分栏截断的段落必须合并后翻译**，不能出现半句成段。
7. **保留上下标与物理符号格式**：`Bi_2Te_3`、`cm^{-2}`、`μV K^{-1}`、`°C`、`Ω`。
8. **对话名称为 `<文件名>-<年份>-翻译`**（如 `未来传感器的10个问题-2026-翻译`）。见下文「会话命名」。
9. **LaTeX 公式必须渲染正确**。行内公式用 `$...$`，独立公式用 `$$...$$`，且必须是合法 LaTeX。

## 输出格式规范

- 顶层标题用 `# 中文标题`，紧随其后一行 `> 原文：<英文标题>` 与 `> 作者：<authors>`。
- 章节标题：`## 1 引言`、`### 2.1 器件制备`（保留原文编号）。
- 摘要用 `## 摘要`，关键词用 `**关键词：**`。
- 图注：`**图 1.** ...`；表注：`**表 1.** ...`。
- 公式：独立成行的编号公式写成
  ```
  $$
  zT = \frac{S^2 \sigma T}{\kappa} \tag{1}
  $$
  ```
- 术语首次出现时给出中英对照：`塞贝克系数（Seebeck coefficient, S）`。
- 不使用 HTML 标签；不使用 raw 图片语法（原文图片位置写 `<图片：图 N>`）。

## 标准流程

### 第 0 步：确定输入

- 若用户给了 PDF 路径 → 直接进入第 1 步。
- 若用户把 PDF 拖进对话（附件）→ 先确认附件在工作区中的路径（`library/papers/` 下）；取不到路径时请用户把文件放进 `library/papers/`。
- 若用户直接粘贴了英文文本 → 跳过第 1 步，直接翻译，但仍需确定 slug 与年份。

### 第 1 步：抽取干净源文本

```powershell
node '<workspace>/tools/extract_pdf.mjs' '<pdf路径>' --out '<workspace>/library/extracted' --name '<slug>'
```

抽取器已经处理：双栏重排、页眉页脚与页码剔除、跨页断段合并、行尾断词还原（`defor-\nmation` → `deformation`）、上下标转 LaTeX、参考文献段落标记。

产出 `library/extracted/<slug>/<slug>.md`，其中：
- `===PAGE n===` 为原页码锚点；
- `===SEC:ABSTRACT===`、`===SEC:INTRODUCTION===`、`===SEC:REFERENCES===` 等为章节标记，**这些标记本身不要出现在译稿中**。

**必读抽取报告**（`<slug>.report.txt`）：若报告显示「判定为双栏的页」与实际不符，或段落数异常少，说明该 PDF 版面特殊（例如整页扫描件、三栏、竖排）。此时：
- 扫描件（无文本层）→ 明确告知用户无法抽取文本，请其提供可复制文本的 PDF 或 OCR 后的文本；
- 其余情况 → 用 `--pages` 分页排查，并在译稿末尾附注「本页版面自动识别存疑」。

### 第 2 步：通读并规划

读完整篇抽取文本后再动笔。先列出：章节结构、图表清单、需要保留的引用标注、关键术语表（中英对照）。术语翻译全文必须一致。

### 第 3 步：逐段翻译

- 按 `===SEC:...===` 分段翻译，译完一段即写入译稿文件，避免长文一次性生成时中断丢失。
- 遇到 `===PAGE n===` 标记：只作为阅读顺序锚点，不要输出到译稿。
- 遇到 `===SEC:REFERENCES===` 之后的内容：**停止翻译**，保留原文标题 `## 参考文献`，其余一律不译。
- 抽取文本中的 `^{-2}`、`_{2}` 是上下标标记，翻译时**必须转成合法 LaTeX**：`cm^{-2}`、`Bi_{2}Te_{3}`。
- 若原文一行是公式（`$...$` 包裹或含 `=` 的短行），先核对 LaTeX 是否合法再写入译稿；不确定时保留原符号形式并加 `*` 标注。

### 第 4 步：写文件并入库

译稿写入 `library/translations/<slug>/<slug>.md`（目录不存在则先创建）。然后登记：

```powershell
node '<workspace>/tools/library.mjs' add --title '<中文标题>' --slug '<slug>' --year <年份> --authors '<作者>' --category '<分类>' --source '<pdf相对路径>' --extracted '<抽取md相对路径>'
node '<workspace>/tools/library.mjs' set --slug '<slug>' --status translated --translation 'library/translations/<slug>/<slug>.md'
```

年份取原文发表年（见期刊页眉或 DOI）；取不到时用用户给出的年份，再取不到则留空并询问用户。

### 第 5 步：会话命名

把当前对话重命名为 `<文件名>-<年份>-翻译`。

- 若有 `rename_session` 之类的工具：直接调用。
- 否则在回复末尾**明确写出建议名称**，并请用户在侧栏右键重命名：
  > 建议对话名称：`未来传感器的10个问题-2026-翻译`

不要臆造文件名或年份；名称必须来自真实输入。

### 第 6 步：汇报

回复中给出：
- 译稿路径（Markdown 链接）；
- 字数与段落数；
- 未能确定的术语/公式清单（如有）；
- 建议的对话名称。

## 分类体系

默认分类：`热物性`、`传感器`、`自供电`、`机械`、`材料`、`热物理`、`计算机`、`其他`。
按论文主题选择最贴切的一个；跨领域时选主要贡献所在方向，并把另一方向写入 `--tags`。
用户可指定新分类，直接传给 `--category` 即可自动加入索引。

## 常见故障处理

| 现象 | 处理 |
|---|---|
| `无法载入 pdfjs-dist` | 在工作区执行 `npm install`（缓存需指向工作区内：`npm --cache .npm-cache install`） |
| 抽取文本为空或极少 | PDF 无文本层（扫描件）→ 告知用户，不要凭空翻译 |
| 公式渲染成代码 | 检查是否用了 `$...$` / `$$...$$`；反斜杠需转义正确；避免在公式内用中文标点 |
| 段落被切成半句 | 回到抽取报告确认分栏判定；用 `--pages` 重抽问题页 |
| 译稿公式显示为红色报错 | LaTeX 非法，先用 KaTeX 语法自查（`\frac{}{}` 花括号配对、`_`/`^` 后需 `{}`） |

## 禁止事项

- 不翻译参考文献条目。
- 不编造原文没有的数据、图表编号或结论。
- 不把 `*` 标注滥用于普通词汇——仅在确实无通用译法时使用。
- 不在译稿中保留 `===PAGE n===` / `===SEC:...===` 这类内部标记。
